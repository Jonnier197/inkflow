========================================================
  INKFLOW — RED SOCIAL / BLOG
  Proyecto Final de Curso
========================================================

TECNOLOGÍAS USADAS
------------------
  Backend:  Node.js + Fastify + TypeScript
  Frontend: Vite + Vanilla TypeScript (modular)
  Base de datos: PostgreSQL (Neon recomendado)
  Auth: JWT (@fastify/jwt)
  Docs: Swagger UI + OpenAPI 3.0

ENTIDADES DEL SISTEMA
----------------------
  1. users      — Usuarios (id, username, email, password_hash, bio, avatar_url)
  2. posts      — Publicaciones (id, user_id, title, content, image_url, tags, published)
  3. comments   — Comentarios (id, post_id, user_id, content)
  4. likes      — Likes de posts (id, user_id, post_id) — UNIQUE por par
  5. followers  — Relación seguidor/seguido (id, follower_id, following_id)

DIAGRAMA RELACIONAL (simplificado)
-----------------------------------
  users ──< posts        (1 usuario → N posts)
  users ──< comments     (1 usuario → N comentarios)
  posts ──< comments     (1 post → N comentarios)
  users ──< likes        (1 usuario → N likes)
  posts ──< likes        (1 post → N likes)
  users ──< followers    (M:N entre usuarios, auto-referencia)

========================================================
  PASOS PARA EJECUTAR
========================================================

1. CONFIGURAR BASE DE DATOS (Neon)
-----------------------------------
  a) Ir a https://neon.tech y crear una cuenta gratuita
  b) Crear un nuevo proyecto (ej: "inkflow")
  c) Copiar el "Connection String" que tiene el formato:
       postgresql://usuario:contraseña@host/dbname?sslmode=require
  d) Guardar ese string, lo usarás en el paso 3

2. INSTALAR DEPENDENCIAS
--------------------------
  Abre DOS terminales.

  Terminal 1 — BACKEND:
    cd backend
    npm install

  Terminal 2 — FRONTEND:
    cd frontend
    npm install

3. CONFIGURAR VARIABLES DE ENTORNO (BACKEND)
---------------------------------------------
  cd backend
  cp .env.example .env

  Edita el archivo .env con tu editor favorito:
    DATABASE_URL=postgresql://usuario:contraseña@host/dbname?sslmode=require
    JWT_SECRET=una_clave_secreta_larga_y_segura
    PORT=3000
    NODE_ENV=development

4. EJECUTAR MIGRACIÓN DE BASE DE DATOS
----------------------------------------
  (Con el .env ya configurado)
  cd backend
  npm run db:migrate

  Esto crea todas las tablas en tu base de datos Neon.
  Deberías ver:
    ✅ Migración ejecutada correctamente

5. INICIAR EL BACKEND
-----------------------
  cd backend
  npm run dev

  Deberías ver:
    🚀 Servidor corriendo en http://localhost:3000
    📚 Documentación Swagger: http://localhost:3000/docs

6. INICIAR EL FRONTEND
------------------------
  cd frontend
  npm run dev

  Deberías ver:
    VITE v5.x  ready in Xms
    ➜  Local:   http://localhost:5173/

7. ABRIR LA APLICACIÓN
------------------------
  Abre tu navegador en: http://localhost:5173

  Documentación API Swagger: http://localhost:3000/docs

========================================================
  ENDPOINTS PRINCIPALES
========================================================

  Sin token (públicos):
    POST /auth/register    — Crear usuario
    POST /auth/login       — Iniciar sesión

  Con token JWT (Bearer):
    GET  /users/me         — Mi perfil
    PUT  /users/me         — Actualizar mi perfil
    DELETE /users/me       — Eliminar mi cuenta
    GET  /users/search?q=  — Buscar usuarios
    GET  /users/:id        — Perfil de usuario
    POST /users/:id/follow — Seguir/dejar de seguir

    GET  /posts/feed       — Feed personalizado
    GET  /posts            — Todos los posts
    POST /posts            — Crear post
    PUT  /posts/:id        — Actualizar post
    DELETE /posts/:id      — Eliminar post
    POST /posts/:id/like   — Like/unlike

    GET  /posts/:id/comments    — Comentarios del post
    POST /posts/:id/comments    — Agregar comentario
    DELETE /posts/comments/:id  — Eliminar comentario

  Swagger UI completo en: http://localhost:3000/docs

========================================================
  NOTAS IMPORTANTES
========================================================

  - El proxy de Vite redirige /api/* al backend automáticamente.
    Esto significa que desde el frontend, /api/auth/login
    llega al backend como /auth/login.

  - Los únicos endpoints SIN token son /auth/register y
    /auth/login (según los requerimientos del proyecto).

  - Para producción, ejecuta:
      cd backend && npm run build && npm start
      cd frontend && npm run build   (genera carpeta dist/)

  - El diseño usa la fuente Playfair Display + DM Sans
    cargadas desde Google Fonts. Requiere conexión a internet.
